# Modpack Sync

A desktop app for creating and sharing modpacks across multiple games, built with [Tauri 2.0](https://beta.tauri.app/guides/).

![mod-updater.png](.github/mod-updater.png)

## Overview

Modpack Sync makes it easy to create custom modpacks and share them with friends. No manual zip exports or imports, generate a short share code and friends join instantly, with mods syncing automatically.

## Features

- Browse and install mods from Modrinth (for Minecraft) and Thunderstore
- Create modpacks and share them via short codes
- Friends join using share codes, mods sync automatically
- Profile management (multiple mod configurations per game)
- Multi-game support: Minecraft, Lethal Company, Valheim, Risk of Rain 2

## Usage

1. Clone this repository.
2. Install dependencies with `bun install` and run the project using `bun tauri dev`.
3. Select your game, create a modpack, and share it with friends using the generated code.

_**Note:** You can also use the [release](https://github.com/Frenvius/tauri-mod-updater/releases) version._
